# Governance

Bedriox Protocol is maintained through the [Bedriox GitHub organization](https://github.com/Bedriox). Maintainers appointed by the organization make final decisions on roadmap, releases, security response, and repository access.

Material architecture or compatibility changes require a written design proposal approved by the maintainers. Ordinary changes use reviewed pull requests. The project uses GPL-3.0-only inbound and outbound licensing and currently requires no CLA.
